# Opdater stop-status

Som medarbejder kan du under kørsel opdatere **status for hvert stop** på ruten, så alle kan se, hvad der er leveret og hvad der er mislykket.

## Tilgængelige status

Hvert stop kan typisk sættes til én af disse status:

| Status | Betydning |
|--------|-----------|
| **Scheduled** (Planlagt) | Stop er planlagt, endnu ikke påbegyndt. |
| **Delivered** (Afleveret) | Pakken er afleveret ved dette stop. |
| **Failed** (Mislykket) | Levering mislykkedes (fx ingen hjemme, forkert adresse). |

(De præcise navne kan variere lidt i grænsefladen.)

## Sådan opdaterer du et stop

1. Åbn den **rute** du kører (under Leveringsruter).
2. Find **listen over stoppesteder** eller **kortvisningen** med stop.
3. Vælg det **stop** du vil opdatere.
4. Vælg den **nye status** (fx "Afleveret" eller "Mislykket").

Ændringen gemmes på serveren, så andre (fx administratorer) kan se den opdaterede status.

## Hvorfor det er vigtigt

- **Sporbarhed** – Det er tydeligt, hvilke stop der er kørt og hvad resultatet var.
- **Rapporter** – Administratorer kan bruge status til opfølgning og statistik.
- **Kundeservice** – Ved "Mislykket" kan der sættes ekstra leveringsforsøg eller anden handling i gang.

Hvis du ikke kan ændre status på et stop, kan det være fordi din bruger ikke har rettighed til den rute – eller at der er problemer med forbindelsen. Prøv at trække ned for at opdatere listen og tjek din internetforbindelse.
