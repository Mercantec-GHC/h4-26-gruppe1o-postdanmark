# Assets

Put your favicon and other site icons here.

- **`favicon.ico`** – Used as the browser tab icon (e.g. 32×32 or 16×16).
- Optionally: `icon.svg`, `apple-touch-icon.png` for better support on different devices.

The site is configured to use `/assets/favicon.ico` as the favicon. Add that file and it will appear in the tab.
